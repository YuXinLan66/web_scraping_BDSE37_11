
使用 Python 爬取 Project Gutenberg 網站上的中文書籍文字內容並儲存為 '.txt' 檔案的工具。

## 專案簡述

這個專案旨在自動化從 Project Gutenberg 網站下載中文書籍的文字內容。它首先抓取中文書籍列表的連結，然後針對每個連結的頁面，提取不包含英文字母的段落文字，並將其儲存到以書籍標題命名的 '.txt' 檔案中。

## 主要特色

* **自動化抓取書籍列表：** 從 Project Gutenberg 的中文書籍列表頁面自動獲取書籍連結。
* **提取中文內容：** 能夠識別並提取網頁中不包含英文字母的段落文字。
* **儲存為純文字檔案：** 將提取的中文內容儲存為易於閱讀和處理的 '.txt' 檔案。
* **處理非法字元：** 自動處理書籍標題中的非法字元，以確保檔案可以正確儲存。
* **使用 Selenium 處理動態內容：** 即使網頁內容是動態載入的，也能夠正確抓取。

## 程式碼說明

這個 Python 腳本主要完成以下步驟：

1.  **匯入必要的函式庫：** 引入了 'selenium' 用於瀏覽網頁，'requests' 和 'BeautifulSoup' 用於解析 HTML，'re' 用於處理字串，'os' 用於檔案操作，以及 'time' 用於等待。
2.  **設定目標網址：** 定義了 Project Gutenberg 中文書籍列表的網址。
3.  **抓取書籍列表：** 使用 'requests' 獲取網頁內容，並使用 'BeautifulSoup' 解析 HTML，提取包含書籍標題和連結的 '<a>' 標籤。
4.  **處理書籍連結：** 從連結中提取書籍的編號，並將書籍標題和編號儲存到 'list_posts_href' 列表中。
5.  **設定儲存資料夾：** 創建一個名為 'project_gutenberg' 的資料夾用於儲存下載的書籍檔案。
6.  **初始化 Selenium WebDriver：** 啟動 Chrome 瀏覽器以模擬使用者操作。
7.  **遍歷書籍列表並下載內容：**
    * 針對列表中的每一本書，構建書籍內容頁面的 URL。
    * 使用 Selenium 打開該 URL。
    * 等待網頁的 'body' 元素加載完成。
    * 提取網頁 'body' 中的所有段落文字。
    * 篩選出不包含英文字母的段落。
    * 將這些段落寫入以書籍標題命名的 '.txt' 檔案中，並處理標題中的非法字元。
    * 如果在頁面中找不到不包含英文字母的段落，則會印出相應的訊息。
    * 為了避免對網站造成過大的負載，程式會在每次請求後等待 1 秒。
8.  **錯誤處理：** 使用 'try...except...finally' 結構來捕獲可能發生的異常，並確保在程式結束時關閉瀏覽器。

## 注意事項

* 請確保 ChromeDriver 版本與 Chrome 瀏覽器版本相符。
* 由於這個腳本會自動訪問網站並下載內容，請遵守 Project Gutenberg 的使用條款和網站的 'robots.txt' 協議。
* 網路狀況可能會影響下載速度和程式的穩定性。
* 如果遇到任何錯誤，請檢查終端機輸出的錯誤訊息以進行排查。
